API REFERENCE

From zero to first request.

The prototype runs locally. Create a key in PowerShell, then send it using the X-API-Key header.

EndpointsGET /v1/bahGET /v1/usageError responses

API keys are managed from the local command line in v0.4. Self-service signup comes later.

GET/v1/bah

Return the published monthly and annual BAH amount for an eligible duty-station ZIP.

zip5-digit duty-station ZIP
gradee.g., E-5, W-2, O-3
dependentstrue or false
year2026 (default)
$headers = @{ "X-API-Key" = "YOUR_API_KEY" }
Invoke-RestMethod -Uri "http://localhost:3000/v1/bah?zip=92136&grade=E-5&dependents=true&year=2026" -Headers $headers
GET/v1/usage

Return your plan, calendar month, requests used, monthly quota, and requests remaining.

Error responses

400Invalid request parameters
401Missing, invalid, or revoked API key
404ZIP or rate not found
429Monthly plan limit reached
503Requested year not loaded
